# 剪贴板自动输入工具（适用于学习通等禁止粘贴的输入框）

一个仅需 Python 的小工具：读取剪贴板里的文字，然后**模拟键盘逐字输入**，把它"敲"进当前光标所在的位置。

很多在线平台（如学习通/超星、部分作业与考试系统）会拦截 `Ctrl+V` 粘贴，但无法区分真正的键盘输入和本工具模拟的按键。因此，凡是禁止粘贴的输入框，都可以用本工具把文字自动打进去。

## 功能特性

- **绕过粘贴限制**：不调用剪贴板粘贴，而是通过 Windows `SendInput` 逐字符发送键盘事件
- **完整支持中文**：使用 Unicode 方式输入，不依赖输入法，中文、emoji、生僻字（UTF-16 代理对）都能正常输出
- **保留格式**：换行转为回车，制表符转为 Tab
- **随时中断**：`F12` 立即停止输入，不必等整段文字打完
- **热键防误触**：开始输入前会等待 `Ctrl` / `Alt` 释放，避免修饰键污染文本
- **单实例保护**：输入过程中重复触发热键不会重复开线程

## 环境要求

- **Windows 10 / 11**（脚本使用 Win32 API，不支持 macOS / Linux）
- Python 3.8 及以上

## 安装

```bash
pip install keyboard pyperclip
```

## 使用方法

1. 运行脚本：

   ```bash
   python h.py
   ```

   看到提示 `脚本运行中：Ctrl+Alt+V 开始输入，F12 停止，Ctrl+C 退出` 即启动成功。

2. 复制你想输入的文字（`Ctrl+C`）。

3. 用鼠标点击网页中**禁止粘贴的输入框**，让光标停在里面。

4. 按下 `Ctrl+Alt+V`，脚本开始逐字输入。

5. 需要中断时按 `F12`；结束整个脚本在命令行窗口按 `Ctrl+C`。

> 输入的快慢由脚本开头的 `DELAY` 控制，默认每个字符间隔 0.03 秒。如果目标网站反应慢、出现漏字，可以适当调大：

```python
DELAY = 0.03   # 每个字符之间的间隔（秒）
```

## 工作原理

脚本通过 `ctypes` 调用 Windows 的 [`SendInput`](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput) 接口，以 `KEYEVENTF_UNICODE` 标志直接发送字符的 UTF-16 码元。这相当于用户在物理键盘上敲下这些字，完全绕开网页层的复制 / 粘贴事件拦截。

## 常见问题

**Q：中文会变成乱码或打不出来？**
本脚本不依赖输入法，中文是以 Unicode 码点直接发送的。若目标程序内部对输入做了特殊处理，可尝试把目标窗口切到前台后再触发。

**Q：按了 `Ctrl+Alt+V` 没反应？**
- 确认命令行窗口显示已在运行；
- 确认光标确实在可编辑的输入框内；
- 如果目标程序是**以管理员身份运行**的，Windows 会阻止普通程序向它发送按键，此时请同样以管理员身份运行本脚本。

**Q：输入中途丢失字符？**
调大 `DELAY`（例如 `0.05` 或 `0.1`），部分网页（尤其是富文本编辑器）需要更长的处理时间。

**Q：可以在游戏 / 远程桌面里用吗？**
部分游戏反作弊或受保护窗口会忽略 `SendInput`，这类场景无法保证生效。

**Q：整段文字太长怎么办？**
脚本会不停顿地逐字输入，期间请不要切换窗口或操作鼠标键盘。较长文本建议分段复制、分段触发，或按 `F12` 中断后重新开始。
